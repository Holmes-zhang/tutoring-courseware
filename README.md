# 可复用家教课件模板

把知识讲解、当堂任务、参考解析和课堂板书放在一个 HTML 文件里。整理自家教备课与授课时使用的模板；换一课时，主要替换内容，不必重新搭版式。

它保留了我实际需要的几件事：讲题时先收起解析，按需展开；要推导时直接在课件上写；课后把正文与解析打印成 PDF。示例内容是通用占位文字和基础数学题，不包含真实学生记录。

[在线预览](https://holmes-zhang.github.io/tutoring-courseware/) · [使用此模板](https://github.com/Holmes-zhang/tutoring-courseware/generate)

想保存自己的版本，可以点击仓库上方的 **Use this template → Create a new repository**，再修改新仓库 `index.html` 中的 `const LESSON`。

## 开始使用

1. 下载 `index.html`，用现代浏览器打开。课件、公式脚本与字体都在文件内，打开后不需要联网。
2. 先查看 8 页示例：封面、章节导航和 6 个内容页。
3. 复制并重命名 HTML，用文本编辑器搜索 `const LESSON`，替换这一段的课程内容。

HTML 文件可以直接发送给授课设备，也可作为静态页面部署。GitHub 仓库中的文件预览会显示源码；演示时可以打开上方的在线预览，或在本地打开下载的文件。

## 内容怎么换

`LESSON` 包含 `title`（封面标题）、`subtitle`（副标题）、`subject`（学科与年级）、`year` 和 `pages`（内容页数组）。复制一个完整的页面对象，就可以添加一页；章节目录和页数会自动生成。

```javascript
{
  section: "01 方程与方法",
  title: "先想因式分解",
  layout: "focus",
  body: ["先判断是否能找到两个合适的整数。"],
  task: [String.raw`解方程：\(x^2-5x+6=0\)。`],
  answer: [String.raw`\((x-2)(x-3)=0\)，所以 \(x_1=2,\ x_2=3\)。`],
  tip: "先独立尝试，再展开解析。"
}
```

| 字段 | 用途 |
| --- | --- |
| `section` | 章节名；同一章节的页面建议连续排列 |
| `title` | 本页标题 |
| `layout` | `focus`、`cards`、`visual-left` 或 `visual-right` |
| `body` | 知识讲解的段落数组 |
| `task` | 例题或当堂练习的段落数组 |
| `answer` | 解析的段落数组 |
| `tip` | 页底提醒，不需要时写空字符串 |
| `figure` | 可选内置图形：`triangle`、`area` |
| `svg` | 可选完整 SVG 字符串，优先于内置图形 |

四种版式分别用于无图讲解、方法比较、左图右文和右图左文。图文版式没有有效图形时，会回退到无图版式。

公式用 `String.raw` 保留反斜线，行内公式放在 `\(` 与 `\)` 之间，独立公式放在 `\[` 与 `\]` 之间。普通段落按文本显示，不能在 `body` 等字段里直接写 HTML。自定义 `svg` 是例外：它会作为图形插入页面，只使用自己编写或已经检查过的 SVG；外部图片链接也会破坏离线使用。

## 授课时的操作

| 操作 | 按钮或快捷键 |
| --- | --- |
| 翻页 | 上一页／下一页；方向键、空格、PageUp／PageDown |
| 跳到首尾页 | Home／End |
| 定位某一页 | 目录、页码输入框，或地址末尾的 `#slide-N`（从 1 开始） |
| 显示／隐藏解析 | 点击解析标题，或按 A |
| 全屏 | 全屏按钮；退出也可按 Esc |
| 书写 | 点击“开启板书”，再选择笔或橡皮 |
| 改笔色 | 点击“颜色”，选择后自动收起色板 |
| 删除笔画 | 框选后点击“删除所选”，或按 Delete／Backspace |
| 撤销 | 板书开启时，Ctrl+Z（Mac 为 ⌘Z） |
| 重做 | 板书开启时，Ctrl+Y 或 Ctrl+Shift+Z（Mac 可用 ⌘Shift+Z） |

框选只要碰到一条笔画的采样点，就会选中整条笔画。删除、清空和擦除都可以撤销；每页的笔迹与操作历史分别保存。板书开启时，画布会接管页内的鼠标和触控输入；需要点击解析标题等内容时，可以先关闭板书，或使用 A 键。

**板书是临时的。** 翻页再返回仍有笔迹，但刷新或关闭页面会清除全部板书。需要保留课堂笔迹时，请在刷新前截图；当前没有板书存档或导入功能。浏览器只会记住会议模式的开关偏好。

会议模式将画布像素密度降为 1，并关闭翻页动画，适合共享屏幕时尝试。它保留矢量笔迹、压感采样和撤销记录；没有对特定会议软件的性能提升做量化测试。

## 设备与打印

支持鼠标、触控和普通电容笔；这几类输入使用固定笔宽。只有设备和浏览器把输入报告为 `pen`，并提供有效 `pressure` 时，笔宽才会随压力变化。压感、掌拒和书写延迟依赖具体硬件、驱动及浏览器，本项目没有承诺通用掌拒，也没有覆盖全部数位板和平板设备的实测。

按 Ctrl+P（Mac 为 ⌘P）并选择“另存为 PDF”。建议关闭页眉页脚、开启背景图形；模板使用横向页面，一页课件对应一页纸。打印时会展开解析，隐藏工具栏与板书；关闭打印预览后恢复解析原来的状态。

内容过长时需要拆页。模板不会自动分页或缩小长段落；请同时检查“解析展开”的画面与打印预览。手机竖屏会提示旋转，授课建议使用横屏。

## 文件与实现

```text
.
├── index.html              # 内容、样式、板书脚本、公式脚本和字体
├── README.md               # 使用说明与限制
├── CHANGELOG.md            # 本次公开整理的改动
└── third-party-notices/    # 内嵌第三方代码与字体的许可文本
```

页面由 `LESSON.pages` 生成，普通文字会先转义。板书用 Canvas 显示、以逐点矢量笔画保存，每页维护自己的撤销与重做记录；隐藏页释放高分辨率画布，返回时重建。数位笔的合并采样按帧绘制。没有后台服务、账号系统或课件内容上传逻辑。

内置示例已通过 6 段脚本的语法检查与 18 处公式的 KaTeX 渲染检查，并检查了运行时资源的离线引用。压感与触控仍需在实际授课设备上试写。

## 已知限制与第三方资源

- 当前版本侧重备课后的演示，编辑内容仍需要文本编辑器。
- 调整窗口大小、切换显示器或进入全屏时，笔迹保留原来的像素坐标，不会自动贴合重新排版后的文字；建议先确定演示窗口，再开始板书。
- 浏览器必须支持 Canvas、现代 JavaScript、`<dialog>` 和 Fullscreen API；内嵌浏览器可能限制全屏。
- 内嵌中文字体是 Noto Sans SC 与 Noto Serif SC 的字符子集，未包含的字会使用设备上的中文字体；不同设备显示可能略有差异。
- 内嵌 KaTeX 为 0.16.11。[KaTeX 代码](third-party-notices/KaTeX-MIT-LICENSE.txt)采用 MIT 许可证；[KaTeX 数学字体](third-party-notices/KaTeX-Fonts-OFL.txt)、[Noto Sans SC](third-party-notices/Noto-Sans-SC-OFL.txt) 与 [Noto Serif SC](third-party-notices/Noto-Serif-SC-OFL.txt) 采用 SIL Open Font License 1.1。完整声明也保留在 HTML 的 `third-party-notices` 模板块内，复制单个课件文件时会一同携带。本仓库暂未另行为模板自身指定许可证，第三方许可不代表整个模板都采用 MIT。
